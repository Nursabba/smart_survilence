Smart Surveillance System

An AI-powered surveillance system developed using Python, OpenCV, and MediaPipe for real-time human detection and monitoring.

Features

- Real-time video surveillance
- Human detection and tracking
- Motion monitoring
- Activity analysis
- Live camera feed processing
- CSV-based event logging

Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy
- Pandas

Applications

- Smart Security Monitoring
- Office Surveillance
- Home Security Systems
- Public Area Monitoring

Future Enhancements

- Face Recognition Integration
- Object Classification
- Alert Notification System
- Cloud-Based Monitoring
